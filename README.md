# PENSMenfess Challenge

## Overview
PENSMenfess adalah sebuah challenge berbentuk aplikasi diary/menfess sederhana. Pengguna dapat mendaftar, membuat postingan menggunakan BBCode, dan berinteraksi dengan aplikasi.

## Feature
- Registrasi dan login pengguna.
- Pembuatan postingan dengan dukungan BBCode.
- Postingan dapat ditandai sebagai publik atau privat.
- Terdapat endpoint API untuk interaksi posting (akses internal/terbatas).

## Setup Instructions

1. **Build and run with Docker Compose:**
   ```bash
   docker-compose up --build
   ```

2. **Access the application:**
   - Main app: http://localhost
   - Bot report interface: http://localhost:5001
